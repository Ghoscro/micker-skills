# Release status

Version: 1.0.0 · License: [MIT](LICENSE) · Package date: 2026-10-12

This package contains four compact public skill editions, a bilingual README for
each, mock examples, the read-only UTF-8 inspector, and repository documentation.
`manifest.json` enumerates all other included files with byte lengths and SHA-256
hashes. The manifest itself is outside its own hash list.

Local verification covers exact inventory, canonical-source/export byte identity,
UTF-8 Markdown, relative links, heuristic sensitive-content scanning, preservation
of original internal skill entries, independent mock-case review, and read-only
inspector black-box fixtures. Documentation and inspector interfaces were also
mapped with ripwire. A map verifies structure; it does not execute the workflows.

The inspector fixtures cover healthy Chinese JSON, BOM JSON, GBK bytes, malformed
JSON, a legitimate Chinese heuristic match, empty text, NUL bytes, missing files,
and unchanged input bytes. Export checks protect unknown files and user edits.

Automatic discovery in specific agent hosts, video extraction integrations,
comparative model behavior, token savings, outside adoption, stars, and revenue
are unmeasured. The three method-only packages require suitable host capabilities.

Micker / Ghoscro with AI collaborators authored these public editions. Known
conceptual inspiration is retained in the relevant entries and READMEs; the
package includes no J-Space or other upstream implementation. The candidate
catalog lists future packaging work, not additional shipped skills.

Only the explicit public package belongs in the GitHub repository. Internal
task records, private source receipts, live databases, private memory, account
data, and deployment configuration remain outside it. Local verification receipts
and publication receipts are maintained separately from the public package.
